# docs/

This folder holds **working notes in Portuguese**, written while building the
game in this repository.

The finished, English handbook that grew out of these notes now lives in its own
repository:

**https://github.com/profsergiocosta/tldr-handbook**

It is a MkDocs site covering installation, fonts and accents, the overworld,
the battle system and a field reference. Corrections belong there.
